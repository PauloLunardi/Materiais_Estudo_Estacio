# Principais SGBDs Relacionais do Mercado e Suas Origens Históricas

## 1. Linhagem Comercial da IBM e a Criação do SQL

O pioneirismo da IBM com o projeto *System R* moldou o padrão da indústria para os bancos de dados relacionais nas décadas seguintes. 

### O Nascimento do DB2

* **Origem:** O projeto experimental *System R* foi transicionado para um produto comercial.
* **Nomenclatura Inicial:** Primeiramente batizado como *Structured Query Language/Data System* (SQL/DS).
* **Consolidação:** Posteriormente renomeado para **DB2**, tornando-se um dos líderes globais no mercado de bancos de dados corporativos de grande porte, com suporte multiplataforma e presença na nuvem.

### A Linguagem SQL

* **Conceito:** Criada pela IBM como o mecanismo padrão de consulta e manipulação para o modelo relacional.
* **Impacto Comercial:** A linguagem tornou-se um padrão universal da indústria tão forte que a sigla "SQL" passou a ser tratada como sinônimo do próprio conceito de SGBD relacional.

## 2. Ecossistema Oracle e a Web

A Oracle consolidou-se como a maior potência comercial em bancos de dados corporativos e, posteriormente, no ambiente Web. 

### SGBD Oracle

* **Evolução da Empresa:** O desenvolvimento começou na *Software Development Laboratories* (SDL), que depois mudou para *Relational Software Inc.* (RSI) e, por fim, consolidou-se como **Oracle Corporation**.
* **Posicionamento:** Detém o posto de SGBD comercial líder do mercado global corporativo.

### SGBD MySQL e a Pilha LAMP

* **Aquisição:** Em 2010, a Oracle adquiriu a *Sun Microsystems* (empresa de hardware que gerenciava projetos de código aberto) e assumiu o controle do MySQL.
* **Perfil do MySQL:** É o SGBD relacional de código aberto mais popular no desenvolvimento de sistemas para a Web.
* **O Padrão LAMP:** O MySQL tornou-se a peça central da arquitetura que dominou a internet, definida pela sigla: 

  * **L**inux (Sistema Operacional)
  * **A**pache (Servidor Web)
  * **M**ySQL (Banco de Dados)
  * **P**HP (Linguagem de Programação)

## 3. Linhagem do Projeto Ingres (Sybase, SQL Server e PostgreSQL)

A vertente acadêmica desenvolvida na Universidade da Califórnia em Berkeley (UCB) gerou o código-fonte em linguagem C que serviu de base para grandes sistemas modernos. 

### Origem do Microsoft SQL Server via Sybase

* **Distribuição Livre:** O código original do projeto *Ingres* foi distribuído livremente pela UCB junto com o sistema operacional Unix BSD (*Berkeley Software Distribution*).
* **Comercialização:** Pesquisadores adaptaram esse código livre em C para construir o SGBD comercial **Sybase**.
* **Parceria com a Microsoft:** Na década de 1990, a Microsoft firmou uma parceria com a Sybase utilizando essa base tecnológica para dar origem ao **SQL Server**, que figura hoje como um dos líderes de mercado.

### Evolução para o PostgreSQL

* **O Projeto Postgres:** Como evolução direta do Ingres na academia, pesquisadores criaram o *Postgres* (*post ingres*), estendendo o modelo relacional clássico com conceitos de Programação Orientada a Objetos (modelo objeto-relacional).
* **O PostgreSQL Moderno:** Com a incorporação nativa da linguagem SQL na década de 1990, o sistema foi rebatizado como **PostgreSQL**. É amplamente reconhecido no mercado como o SGBD de código aberto (*open source*) mais avançado do mundo.

**Nota de Estudo:** O **MySQL** e o **PostgreSQL** constituem as ferramentas mais utilizadas no ambiente acadêmico para o ensino de bancos de dados devido à sua alta popularidade, documentação robusta e licenças gratuitas.
