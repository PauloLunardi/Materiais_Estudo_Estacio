# Leituras Complementares e Referências Bibliográficas

Este documento reúne recomendações de literatura técnica avançada para o aprofundamento nos tópicos de engenharia de software com Python, além do levantamento bibliográfico utilizado no módulo.

---

## Próximos Passos de Estudo (Explore +)

### Frameworks e Metaclasses
O desenvolvimento de frameworks com metaclasses é um assunto avançado e de grande relevância no mercado de arquitetura de software.
* **Obra Recomendada:** *Fluent Python*
* **Autor:** Luciano Ramalho
* **Ano e Editora:** 2015, O'Reilly Media

### Padrões de Projeto (Design Patterns)
Os padrões de projeto devem ser estudados e aplicados na construção de sistemas orientados a objetos de qualquer porte para garantir modularidade e reuso.
* **Obra Recomendada 1:** *Clean Code in Python: Refactor your legacy code base*
* **Autor:** Mariano Anaya
* **Ano e Editora:** 2018, Packt Publishing
* **Obra Recomendada 2:** *Learning Python Design Patterns*
* **Autor:** Chetan Giridhar
* **Ano e Editora:** 2018, Packt Publishing

### Testes Unitários
Os testes unitários buscam garantir a qualidade, a estabilidade e a cobertura da implementação de acordo com as regras de negócios descritas.
* **Obra Recomendada:** *Python Unit Test Automation: Practical techniques for Python developers and testers*
* **Autor:** Ashwin Pajankar
* **Ano e Editora:** 2017, Apress
