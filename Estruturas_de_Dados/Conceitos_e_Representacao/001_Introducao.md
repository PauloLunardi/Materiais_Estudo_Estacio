# Estruturas de Dados em Linguagem C
## Projeto Prático: Base Lógica do Jogo WAR

**Profª:** Daisy Albuquerque

---

## 📌 Introdução

Boas-vindas ao desafio de programação, no qual você construirá uma versão digital do clássico jogo **War** utilizando a linguagem C!

Imagine o cenário: uma empresa inovadora e especializada em jogos estratégicos contratou você para integrar a equipe responsável por transformar esse jogo icônico em uma experiência interativa e moderna. 

Seu objetivo principal é construir a base lógica do jogo utilizando **estruturas de dados**, **modularização**, **ponteiros** e técnicas de **alocação dinâmica de memória** para conquistar a Ásia e a América do Sul. Desafiador, não é mesmo?

No mercado de trabalho da área de tecnologia, dominar esses conceitos é essencial para o desenvolvimento de sistemas, jogos e aplicações que exigem alta performance e controle sobre os recursos computacionais. Portanto, este desafio vai além da teoria: ele prepara você para a prática profissional com um projeto divertido, estratégico e dinâmico.

---

## 🎯 Objetivos de Aprendizagem

Ao longo deste projeto, você irá desenvolver as seguintes competências práticas:

* **Cadastro de Dados:** Desenvolver um programa que implemente um sistema em C para cadastro de informações básicas do jogo (nome, cor e tropas) utilizando um vetor de estruturas (`structs`).
* **Sistema de Ataque:** Implementar a funcionalidade de ataque entre territórios, utilizando alocação dinâmica e ponteiros para simular batalhas e aproximar o sistema do comportamento estratégico do jogo real.
* **Condição de Vitória:** Implementar o sistema de missões estratégicas utilizando ponteiros e alocação dinâmica para verificar as condições de vitória e concluir o desenvolvimento do jogo.

## 🧠 Conceitos Chave Explorados

* Estruturas de Dados (`struct`)
* Ponteiros e Referências
* Alocação Dinâmica de Memória (`malloc`, `free`)
